# snug-site

Public pages for the Snug Android app, served by GitHub Pages:

- `index.html`: home
- `faq.html`: FAQ (the app's Help screen links here)
- `ai.html`: build layouts with AI (the layout format; the app links here) and `layout.schema.json`, its JSON Schema
- `privacy.html`: privacy policy (linked from Google Play and the app)
- `terms.html`: terms of use

Plain HTML and one stylesheet, no build step and no third-party requests.
